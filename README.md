## ⚡ What is DevCost Lens?

**If OpenAI, Claude, Gemini, and Grok had an electricity meter — this is it.**

DevCost Lens is not another ChatGPT wrapper. It’s a **cost observability platform** that sits between you and 15+ LLMs.

```
You → DevCost Lens (Meter + Vault) → 15+ Models → Real Cost Before You Pay
```

**Core pillars:**
- 🔐 **Secure Vault** — Your keys, AES-GCM 256-bit encrypted in-browser. We can’t see them.
- 🧮 **Real Token Counter** — tiktoken + Claude tokenizer + Gemini counter. No estimates.
- ⚖️ **Instant Alternatives** — “Use Gemini Flash for this, 97% cheaper, same quality.”
- 📊 **Real-time Dashboard** — Live spend, predictions, per-project tracking.

## ⚡ Quick Start (For Developers)

```bash
git clone https://github.com/AbdurRahmanKhan000/DevCost-Lens.git
cd DevCost-Lens
npm install

# Add env vars in .env.local
# NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
# CLERK_SECRET_KEY=
# NEXT_PUBLIC_SUPABASE_URL=
# NEXT_PUBLIC_SUPABASE_ANON_KEY=

npm run dev
```

Open `http://localhost:3000` — Your local smart meter is live.

Full setup guide in `/docs` (coming soon).
